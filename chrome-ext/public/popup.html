💡 如何找到CSS选择器？

方式1: 使用智能查找（推荐）

1. 在AI网站打开对话并获得回答 2. 点击扩展图标打开设置 3. 点击"🔍 智能查找"按钮 4. 从列表中选择合适的按钮 5. 自动填充到配置中

方式2: 手动查找

1. 在AI网站按 F12 打开开发者工具 2. 右键点击COPY按钮 → 选择"检查" 3. 在Elements标签，右键高亮的元素 4. 选择 Copy → Copy selector 5. 粘贴到"COPY按钮选择器"输入框 6. 点击"添加配置"并保存设置

常见选择器示例：
• button[aria-label="Copy"]
• button.copy-button
• [data-testid="copy-btn"]
